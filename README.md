# parfumsbot

Бот находит новинки парфюмерии на [Parfumo](https://www.parfumo.com) и публикует их в Telegram-канал на украинском: фото флакона, бренд, год, характер аромата, парфюмер и пирамида нот со ссылкой на источник.

## Как это работает

Каждый день в 11:00 по Киеву (`.github/workflows/post.yml`) бот берёт все ароматы текущего года, добавленные на Parfumo с прошлого запуска, и раскладывает их по тирам бренда (`data/brand_tiers.json`):

- 👑 **Люкс** и 💎 **Ніша**: отдельный пост с фото, пирамидой нот, строкой «Нагадує…» (похожие ароматы) и ссылками на Parfumo и Fragrantica.
- ⭐ **Дизайнерський** и 🕌 **Арабська парфумерія**: один дайджест дня, альбом фото и список по тирам.
- 💰 **Масмаркет** и 🌱 **Інді**: копятся и выходят списком по воскресеньям.
- По воскресеньям ещё **топ недели**: самые популярные на Parfumo новинки из вышедших в канале за 7 дней.

Ароматы без фото бот ждёт до 7 дней. Бренд, парфюмер, тир и ноты оформлены хэштегами.

**Поиск в личке** (`.github/workflows/dm.yml`): напишите боту бренд, ноту, парфюмера или тир, и он пришлёт список новинок из канала (`data/catalog.json`). Ответ приходит в течение 5–15 минут: GitHub запускает проверку сообщений не чаще раза в 5 минут.

Ручной запуск: **Actions → Публікація новинок → Run workflow**. `since_days` = опубликовать всё за N дней, `weekly` = `yes`, чтобы выпустить недельные сводки сейчас.

## Настройка

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHANNEL` | `@имя_канала` (бот должен быть администратором канала) |
| `ANTHROPIC_API_KEY` | необязательно, для перевода незнакомых нот |

## Локальная проверка

```bash
pip install -r requirements.txt
python -m bot.main --dry-run          # показать посты, ничего не отправлять
```
