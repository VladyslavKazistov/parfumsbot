# parfumsbot

Бот находит новинки парфюмерии на [Parfumo](https://www.parfumo.com) и публикует их в Telegram-канал на украинском: фото флакона, бренд, год, характер аромата, парфюмер и пирамида нот со ссылкой на источник.

## Как это работает

1. Каждые 3 часа GitHub Actions запускает `python -m bot.main` (файл `.github/workflows/post.yml`).
2. Бот берёт недавно добавленные ароматы и самые популярные релизы текущего года.
3. Пропускает уже опубликованные (`data/posted.json`) и те, у которых ещё нет фото. Их он попробует снова в следующий раз.
4. Ноты переводит по словарю `data/notes_uk.json`. Если задан `ANTHROPIC_API_KEY`, незнакомые ноты переводит Claude и дописывает их в словарь. Без ключа незнакомые ноты остаются на английском.
5. Публикует не больше `MAX_POSTS` постов за запуск и сохраняет список опубликованного.

## Настройка

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHANNEL` | `@имя_канала` (бот должен быть администратором канала) |
| `ANTHROPIC_API_KEY` | необязательно, для перевода незнакомых нот |

## Локальная проверка

```bash
pip install -r requirements.txt
python -m bot.main --dry-run          # показать посты, ничего не отправлять
```
